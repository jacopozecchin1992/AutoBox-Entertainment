# AutoBox Entertainment Universale

App Android universale con interfaccia AutoBox, navigazione, velocità GPS, comunicazioni e collegamenti a servizi streaming. I video sono destinati all'uso da parcheggiati.

**Nota:** questo APK Android non è automaticamente compatibile con l'interfaccia Android Auto; la build verificata è destinata allo smartphone.

Il workflow GitHub Actions genera e firma un APK debug da scaricare dagli artefatti della build.
